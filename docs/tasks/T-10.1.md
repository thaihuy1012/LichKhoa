# Phiếu T-10.1: Lõi `src/export/install.ts` + `public/shortcut-links.json` + unit

## Việc cần làm

### Phạm vi file

### Yêu cầu + tiêu chí nghiệm thu
Theo SPEC §5 (chữ ký `export/install.ts`), §3 IN-14, §6 M10 gạch tiêu chí 1 (unit `install.test.ts`).

#### Từ SPEC §5 — Kiến trúc
`export/install.ts` (v1.11, thuần, Vitest): danh mục 5 Phím tắt (`SHORTCUT_KINDS` đúng thứ tự cài, `SHORTCUT_DEFAULT_NAMES`, `SHORTCUT_STATE_KEY`), `parseShortcutLinks` (JSON bất kỳ → 5 url hoặc `null`, không ném), `shortcutNameMismatch`. `Guide.tsx` chỉ fetch JSON + render; không dispatch, không đụng store ngoài đọc state qua `useStoreState`. Link không đi qua `openShortcut` (là `<a>` thường, không phải deep link `shortcuts://`).

#### Từ SPEC §3 IN-14 — Cài bộ Phím tắt bằng link iCloud
**Nguồn link**: file tĩnh `public/shortcut-links.json`:
```
{ "updated": "YYYY-MM-DD" (tùy chọn), "shortcuts": { "wallpaper": { "url": "" }, "alarm": { "url": "" }, "reminder": { "url": "" }, "dayAlarm": { "url": "" }, "morning": { "url": "" } } }
```
KHÔNG nằm trong `AppState`/JSON sao lưu, KHÔNG có ô nhập link trong app. `Guide.tsx` tải khi mount bằng `fetch(import.meta.env.BASE_URL + 'shortcut-links.json', { cache: 'no-cache' })`; không precache (SW `generateSW` chỉ gom js/css/html; cài Phím tắt vốn cần mạng). `parseShortcutLinks` (thuần, `export/install.ts`) không ném: url phải khớp `ICLOUD_SHORTCUT_URL = /^https:\/\/www\.icloud\.com\/shortcuts\/[0-9a-f]{32}$/`, sai/thiếu → `null`.

Thẻ Hướng dẫn số 2 `guide-card-installShortcuts`: 5 hàng `sc-row-<kind>` theo thứ tự cài `SHORTCUT_KINDS` = `wallpaper` · `alarm` · `reminder` · `dayAlarm` · `morning`; mỗi hàng: số thứ tự, tên mặc định (`sc-name-<kind>`, chữ mono), công dụng một dòng, và đúng một trong hai: nút `<a class="btn" data-testid="sc-install-<kind>" href="<url>" target="_blank" rel="noopener noreferrer">` "Tải" / "Get" (cao ≥ 44 pt, không JS — từ PWA standalone link khác origin mở ở trình duyệt trong-app hoặc thẳng app Phím tắt) **hoặc** dòng `sc-nolink-<kind>` "Chưa có link — dựng tay theo các thẻ bên dưới". Không tải được JSON (offline / 404 / hỏng) → dòng `sc-links-error` ("Không tải được danh sách link — cần mạng…") + 5 hàng nolink; thẻ không trắng, không ném lỗi. Có `updated` hợp lệ → dòng `sc-updated`. Không hiện URL dạng chữ.

**Cảnh báo lệch tên** `sc-name-mismatch-<kind>` (4 kind có tên trong `AppState`; `morning` không có): khi `state[SHORTCUT_STATE_KEY[kind]] !== SHORTCUT_DEFAULT_NAMES[kind]` → "Tên trong app đang là "X", Phím tắt tải về tên "Y" — Xem trước › Đổi tên Phím tắt › Khôi phục tên mặc định" (nút của B-018). Chỉ đọc state, không dispatch.

#### Từ SPEC §6 M10 — Tiêu chí 1
[ ] Unit `install.test.ts`: `parseShortcutLinks(json)` → cả url valid, url invalid (regex), `updated` hợp lệ/lỗi; khóa lạ bỏ qua; không ném với mọi đầu vào. `shortcutNameMismatch(state, kind)` các kind lần lượt; morning → luôn null. `SHORTCUT_KINDS`, `SHORTCUT_DEFAULT_NAMES`, `SHORTCUT_STATE_KEY` không thiếu, đúng thứ tự, dữ liệu khớp `defaultState` từ `model.ts` + `morning` không có `SHORTCUT_STATE_KEY` (null); `ICLOUD_SHORTCUT_URL` regex khớp url mẫu.

#### Từ SPEC §8.13 — Giới hạn đã biết
(a) link là **công khai**: ai có link đều xem và cài được nội dung Phím tắt (Apple ký; bản đã cài không thu hồi được) → trước khi chia sẻ phải soát không có Text / thông báo / bình luận / danh sách / liên hệ / vị trí riêng; trường có Import Question bị xóa khi chia sẻ; trang link có thể hiện tên iCloud của người chia sẻ (Apple không nói rõ cho Phím tắt) → Quản lý mở link kiểm trước khi commit, hiện tên thật/email → CHẶN và hỏi Chủ dự án.

(g) Cần mạng khi cài; JSON không precache nên offline hiện `sc-links-error`; GitHub Pages cache ≤ 10 phút → link mới hiện trễ vài phút.

#### Chi tiết chữ ký TypeScript (SPEC §5)
```ts
// export/install.ts (v1.11, D-037, thuần — không fetch, không DOM)
type ShortcutKind = 'wallpaper'|'alarm'|'reminder'|'dayAlarm'|'morning';
const SHORTCUT_KINDS: readonly ShortcutKind[];                      // đúng thứ tự cài: wallpaper, alarm, reminder, dayAlarm, morning
const SHORTCUT_DEFAULT_NAMES: Record<ShortcutKind, string>;         // DatHinhNen, ThemBaoThuc, ThemLoiNhac, ThemBaoThucNgay, TaoBaoThucSang — unit test đối chiếu 4 tên đầu với defaultState(); morning chỉ có trong tài liệu
const SHORTCUT_STATE_KEY: Record<ShortcutKind, 'shortcutName'|'alarmShortcutName'|'reminderShortcutName'|'dayAlarmShortcutName'|null>;   // morning → null
const ICLOUD_SHORTCUT_URL: RegExp;                                  // /^https:\/\/www\.icloud\.com\/shortcuts\/[0-9a-f]{32}$/ — id viết thường, không query/hash
type ShortcutLinks = Record<ShortcutKind, string | null>;
parseShortcutLinks(json: unknown): { links: ShortcutLinks; updated: string | null }   // không ném với mọi đầu vào; url không khớp regex / thiếu / không phải chuỗi → null; `updated` không khớp /^\d{4}-\d{2}-\d{2}$/ → null; khóa lạ bỏ qua
shortcutNameMismatch(state: AppState, kind: ShortcutKind): { app: string; expected: string } | null   // state[SHORTCUT_STATE_KEY[kind]] !== SHORTCUT_DEFAULT_NAMES[kind] → { app, expected }; morning → luôn null
```
