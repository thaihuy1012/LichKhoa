# Phiếu T-10.1: Lõi `src/export/install.ts` + `public/shortcut-links.json` + unit

## Việc cần làm
Phạm vi file: `src/export/install.ts` (mới), `public/shortcut-links.json` (mới, 5 khóa url `""`, chưa có `updated`), `tests/unit/install.test.ts` (mới).

**Mục tiêu**: Xuất hàm `parseShortcutLinks` và danh mục 5 Phím tắt iCloud Link (SPEC §5, IN-14, D-037). Mã nguồn chỉ sửa nếu test mới lộ lỗi.

**Yêu cầu + tiêu chí**: SPEC §5 (chữ ký `export/install.ts`), §3 IN-14 (danh mục 5 kind, regex URL, payload không đổi), §6 M10 gạch tiêu chí 1 (unit `install.test.ts` phải kiểm 4 ca test sau):

1. **URL có khoảng trắng đầu-cuối**: `' https://www.icloud.com/shortcuts/<32hex> '` → `null` (giữ các `kind` khác là null hoặc hợp lệ).
2. **Đọc file `public/shortcut-links.json` thật bằng `fs.readFileSync` + `JSON.parse`** (không qua `parseShortcutLinks`): 
   - Khóa cấp gốc ⊆ {`updated`, `shortcuts`} (không khóa lạ).
   - `Object.keys(shortcuts)` sắp xếp = đúng 5 khóa `SHORTCUT_KINDS` (không thừa, không thiếu).
   - Mỗi mục trong `shortcuts` chỉ có khóa `url` (không khóa lạ).
   - Mỗi `url` là `''` (rỗng) hoặc khớp `ICLOUD_SHORTCUT_URL` regex.
   - Nếu có `updated`, dạng `YYYY-MM-DD`.
3. **URL sai kiểm qua `parseShortcutLinks` với JSON đầy đủ** (5 kind, 4 hợp lệ + 1 sai):
   - Test: (a) protocol http:// (không https); (b) thiếu www.; (c) id 31 ký tự; (d) id 33 ký tự; (e) ký tự hoa ABCDEF; (f) có query `?x=1`; (g) có hash `#frag` — mỗi ca sai → kind đó null, 4 kind khác hợp lệ → giữ url hợp lệ.
4. **`updated` định dạng sai**: `updated: '22/09/2026'` (dạng dd/mm/yyyy) → null; `updated: 20260922` (số, không phải chuỗi) → null.
