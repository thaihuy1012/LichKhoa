# Test `tests/e2e/week.spec.ts` dòng 12 fail chập chờn trên webkit — phân tích nguyên nhân

## Đọc
- tests/e2e/week.spec.ts — toàn bộ file, đặc biệt dòng 12 và test liên quan
- playwright.config.ts, playwright.config.webkit.ts (nếu có), cấu hình Playwright dành webkit
- src/ui/screens/Preview.tsx, src/render/*week* (các file liên quan tới bố cục Tuần, tìm theo testid/selector mà test dùng)
- E2E helpers và fixture dùng chung (nếu có trong thư mục tests/)
- Tham khảo: phần "Lỗi chập chờn webkit" trong docs/BAI-HOC.md (nếu có)

## Yêu cầu
Phân tích lý do test dòng 12 của week.spec.ts thỉnh thoảng fail trên webkit (đã thấy 1 lần trong `npm run check` trên Windows). Trả lời:

1. **Các nguyên nhân chập chờn khả dĩ** — liệt kê tối đa 8 nguyên nhân, xếp theo khả năng (cao nhất trước), mỗi mục ghi rõ:
   - Nguyên nhân (ví dụ: "chờ chưa đủ điều kiện", "animation chưa xong", "canvas dựng lại")
   - Bằng chứ ở file:dòng, hoặc "chưa đủ điều kiện / hiện tượng chập chờn của webkit"
   - Tại sao lỗi xảy ra chập chờn (ví dụ: phụ thuộc timing, giờ/ngày hệ thống, service worker, IndexedDB, debounce)

2. **Cách sửa đề xuất** — ưu tiên sửa phía test (chờ đúng điều kiện, sử dụng locator mạnh mẽ) thay vì nới timeout hay skip. Ghi cụ thể:
   - Sửa gì (tên test hoặc helper)
   - Cách sửa mục tiêu (không nêu code mới, chỉ ý tưởng)
   - Tại sao sửa này sẽ khắc phục nguyên nhân trên

3. **Kết quả tái hiện lệnh** (nếu chạy) — nếu có chạy `npx playwright test tests/e2e/week.spec.ts --project=webkit --repeat-each=20` (sau `npm run build`) để kiểm chứng, ghi:
   - Lệnh đã chạy: `npm run build && npx playwright test ...`
   - Kết quả: <số run> pass, <số run> fail (nếu fail, ghi pattern lỗi)
   - Nhận xét: lỗi có tái hiện được hay không
