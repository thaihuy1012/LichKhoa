## Chẩn đoán & cách sửa (YÊU CẦU CHÍNH)
### Nguyên nhân
ReminderDialog.tsx L41–45:
```typescript
useEffect(() => {
  setAt(defaultReminderAt(...));
}, [open]);
```
Khi `.rem-dialog` hiện (`open=true`), effect chạy → `setAt()` với mặc định → **ghi đè giá trị vừa `fill()` cùng cycle**.

**Kết quả:**
- Sự kiện mai 07:30 → mặc định ok → enabled (test mong disabled; fill 23:59 nhưng bị ghi đè)
- Việc không hạn → mặc định hôm nay → disabled (test mong enabled; fill 08:00 nhưng bị ghi đè)

### Cách sửa TRONG TEST
**Áp dụng cho MỌI nơi fill `rem-at`:**

```javascript
// 1️⃣ Chờ giá trị mặc định được set
await expect(page.getByTestId('rem-at')).not.toHaveValue('');

// 2️⃣ Fill giá trị TEST
await page.getByTestId('rem-at').fill('2026-10-05T23:59');

// 3️⃣ XÁC NHẬN giá trị đã set TRƯỚC mọi assert
await expect(page.getByTestId('rem-at')).toHaveValue('2026-10-05T23:59');

// 4️⃣ Rồi mới assert nút
await expect(page.getByTestId('rem-dayalarm')).toBeDisabled();
```

### Danh sách fill cần sửa (từ v1)
