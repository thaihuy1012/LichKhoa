## Ghi chú SPEC liên quan

### SPEC §3 IN-12 — Hướng dẫn "Báo thức đúng ngày"
Hướng dẫn: `docs/HUONG-DAN.md` §E (2 Phím tắt từng bước + bật "Nhạy cảm thời gian") và thẻ 7 trong tab Hướng dẫn (VI/EN).

### SPEC §8.11 — 4 rủi ro đã biết của Báo thức đúng ngày (v1.9)
- (a) Tự động hóa **không đảm bảo 100%**: máy tắt / hết pin / Chế độ nguồn thấp lúc 00:05 → chạy trễ/không chạy
- (b) Chạy **trùng** (tay + tự động cùng ngày) → "Create Alarm" luôn tạo mới; giảm: lọc "Is Completed is No" + "Edit Reminder: Set Is Completed"
- (c) Báo thức một lần sau khi kêu **vẫn nằm (tắt)** trong app Đồng hồ → dọn tay
- (d) **Phải có danh sách Reminders riêng** `BaoThuc` — trỏ nhầm danh sách chung thì mọi lời nhắc trong ngày thành báo thức

### SPEC §10.E — 4 bước dựng (Phía iPhone)
1. **Reminders**: tạo danh sách mới `BaoThuc`, chỉ dùng cho việc này
2. **Phím tắt `ThemBaoThucNgay`**: mở `ThemLoiNhac` → Duplicate → đổi tên → trong "Add New Reminder" đổi List = `BaoThuc`; giữ phần tách dòng
3. **Phím tắt `TaoBaoThucSang`**: 
   - Find Reminders (All Reminders + Filter: List is `BaoThuc`; Due Date is Today; Is Completed is No; Sort by Due Date)
   - Repeat with Each (Reminders)
   - If (Repeat Item › Due Date is after Current Date)
   - Create Alarm (Time = Repeat Item › Due Date; Label = Repeat Item › Title; Repeat = Never)
   - Edit Reminder (Set Is Completed of Repeat Item to Yes)
   - End If / End Repeat
4. **Tự động hóa**: Phím tắt → Tự động hóa → + → Thời điểm trong ngày → 00:05, Hằng ngày → chọn **Chạy ngay** (Run Immediately), tắt **Thông báo khi chạy** (Notify When Run) → hành động "Run Shortcut" `TaoBaoThucSang` → Xong
